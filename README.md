## 线路是什么成色

CN2 GIA 是中国电信精品网（AS4809）的国际段，一直是 VPS 圈里定价偏高的线路。三网 GIA 回程的意思是，不管你家里用的是电信、联通还是移动，回程数据包都走这条精品通道回国，不绕路、不共享普通 163 那条拥堵路段。

MALIBU 的路由配置：
- 电信去程：CN2 直连（AS4809）
- 联通去程：CN2 直连（AS4809）
- 移动去程：CMIN2（AS58807）
- **三网回程：全部 CN2 GIA（AS4809）**

实测回程路由，出洛杉矶之后马上就跳到了 59.43.x.x 这个段，这是电信 CN2 GIA 的标志性 IP 段，全程不绕弯，直连国内各省出口。联通和移动同样走 GIA 回来，没有落入 AS9808 那条晚高峰容易拥堵的普通路线。

晚高峰延迟实测大概在 150—165ms 之间，丢包率极低。用下来一段时间，中途断连的情况基本没碰到。这条线路的稳定性在 $49.9 年付这个价位段里，确实没什么对手。
